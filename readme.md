# GleanFint — Парсер-анализатор банковских выписок (поддерживается только "T-Bank")

**[Открыть приложение в Streamlit](https://operation-tracker.streamlit.app/)** 

Приложение загружает банковскую выписку (CSV/Excel), автоматически очищает данные, разделяет операции на доходы, расходы и переводы (транзит), а также строит визуальную аналитику и генерирует готовый текстовый отчет.

## Основной функционал
* **Автоматический поиск заголовков** в сырых банковских файлах.
* **Умная фильтрация:** отделение реальных расходов от переводов друзьям или между своими счетами.
* **Аналитика:** подсчет сумм по категориям, среднего чека и вывод топ-5 самых дорогих покупок.
* **Визуализация:** построение столбчатых диаграмм средствами Streamlit.
* **Экспорт:** генерация Markdown-отчета, готового для вставки в Notion или Obsidian.

## Как запустить локально

1. Склонируйте репозиторий на свой компьютер.
2. Установите необходимые библиотеки с помощью команды:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите приложение через Streamlit:
   ```bash
   streamlit run main.py
   ```
